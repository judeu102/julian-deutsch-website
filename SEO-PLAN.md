## 5. On-Page-Template (gilt für jede Money-/Service-Page)

**Über der Falz:**
1. H1 mit primärem Keyword + Nutzenversprechen (z. B. „SEO Freelancer aus Essen, der deine Story zum Ranking bringt").
2. Sub-Headline: für wen / was / Ergebnis in einem Satz.
3. Sofort-Beweis: Logo-Leiste, Sterne-Bewertung, oder „X Projekte seit Y".
4. CTA primär (z. B. „Kostenfreies SEO-Audit anfragen").

**Body-Struktur:**
5. Problem/Schmerz beim Wunschkunden (Story-Branding-Hook!).
6. Leistung in 3–5 konkreten Modulen.
7. Ablauf in 3–5 Schritten (Kennenlernen → Audit → Strategie → Umsetzung → Ergebnis).
8. Beweis-Block: 2–3 Mini-Cases mit Zahlen (Sichtbarkeit +X %, Conversion +Y %).
9. Über-mich-Mini (Foto, 3 Sätze, E-E-A-T-Signale: Jahre Erfahrung, Tools, Branchen).
10. FAQ (4–8 Fragen, deckt long-tail-Suchanfragen ab und liefert FAQ-Schema).
11. CTA-Block sekundär (Formular + WhatsApp + Telefon).

**Pflicht-Elemente (technisch):**
- Title-Tag: max 58 Zeichen, Hauptkeyword vorne, Brand hinten.
- Meta-Description: 140–155 Zeichen, mit Nutzenversprechen + CTA.
- Genau 1× H1, danach H2-Hierarchie.
- Alt-Texte mit beschreibendem (nicht stuffenden) Keyword.
- Interne Links zu mindestens 3 verwandten Seiten.
- LCP-Bild als Priority-Hint, kein Lazy-Load auf Above-the-fold-Bildern.

## 8. Technisches SEO (Pflichtkatalog)

**Performance**
- Core Web Vitals: LCP ≤ 2.5 s, CLS ≤ 0.1, INP ≤ 200 ms.
- Bilder als WebP/AVIF, responsive `srcset`, lazy-load nur unterhalb der Falz.
- Fonts: `font-display: swap`, max 2 Schriftfamilien.
- Critical-CSS inline, Rest async. Kein Render-Blocking.
- Hosting: deutscher Server (Hetzner/Mittwald) oder CDN mit DE-Edge.

**Crawling & Indexing**
- `robots.txt` zugänglich, blockiert nur `/admin/`, `/wp-admin/` etc.
- XML-Sitemap automatisch generiert, in GSC eingereicht.
- Canonical-Tags auf jeder Seite.
- 404-Seite mit Suchfunktion und Top-Links.

**Strukturierte Daten (JSON-LD)**
- `Person` (Julian Deutsch) auf `/ueber-mich/`.
- `ProfessionalService` mit `areaServed` = NRW + Deutschland, `priceRange`, `geo`.
- `BreadcrumbList` auf allen Unterseiten.
- `Article` + `FAQPage` auf Blog-Artikeln.
- `LocalBusiness` Markup auf `/seo-essen/` mit Adresse, Öffnungszeiten, Geo.

**Sicherheit & Hygiene**
- HSTS-Header, CSP-Header, kein Mixed-Content.
- HTTP/2 oder HTTP/3.
- Keine Trailing-Slash-Inkonsistenz (eine Variante festlegen, die andere 301-redirecten).
- `hreflang` nicht nötig (nur DE).

**GEO / AI-Sichtbarkeit**
- `llms.txt` im Root: kuratierte Liste der wichtigsten URLs für LLM-Crawler.
- Klare Quellenangaben in Artikeln (LLMs zitieren bevorzugt belegte Aussagen).
- Strukturierte Listen, klare Definitionen, FAQ-Format → wird in AI-Antworten überproportional verwendet.

## 11. Risiken & Stolperfallen

- **Dünne Stadt-Landingpages.** Kopieren mit Stadtnamen-Tausch ist Doorway-Page-Risiko. Jede Stadt-Page braucht echten lokalen Content.
- **Übertriebenes Keyword-Stuffing.** Lieber 1× Hauptkeyword + Synonyme + Nutzersprache als 12× das gleiche Wort.
- **„Generic-AI-Artikel".** Google Helpful-Content-Updates bestrafen austauschbaren Content. Jeder Artikel braucht persönliche Erfahrung, eigene Beispiele, eigene Position.
- **Backlink-Spam.** Keine PBNs, keine gekauften Linklisten. Lieber 5 starke Links als 50 schlechte.
- **Lange Time-to-Rank.** „SEO Freelancer" ist hart umkämpft. Plane mind. 6–9 Monate, bis Bewegung sichtbar wird. Geduld ist die Strategie.
