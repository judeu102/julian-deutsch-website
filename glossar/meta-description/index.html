Meta Description

Die Meta Description ist die kurze Seitenbeschreibung unter dem Title Tag in den Suchergebnissen. Sie ist kein direkter Ranking-Faktor – aber ein massiver Hebel für die Klickrate.

Was ist eine Meta Description?

Die Meta Description ist ein HTML-Meta-Tag im <head>-Bereich einer Seite. Sie beschreibt den Seiteninhalt in 1–2 Sätzen und erscheint in den SERPs direkt unter dem Title Tag.

Beispiel-Code:

<meta name="description" content="SEO Freelancer aus Essen mit 10 Jahren Journalismus-Erfahrung...">

Ist die Meta Description ein Ranking-Faktor?

Nein – Google hat das mehrfach offiziell bestätigt. Die Meta Description selbst beeinflusst das Ranking nicht. Aber: Sie beeinflusst die Klickrate (CTR), und die CTR ist sehr wohl ein Signal. Eine gute Meta Description kann also indirekt zu besseren Rankings führen.

Optimale Länge

  • 140–160 Zeichen sind die sichere Zone.
  • Auf Mobile schneidet Google früher ab.
  • Wenn keine Meta Description gesetzt ist, generiert Google automatisch eine aus dem Seiteninhalt – meist suboptimal.

Was macht eine gute Meta Description aus?

  1. Klares Versprechen – was bekommt der Nutzer auf der Seite?
  2. Relevantes Keyword – Google fettet Keywords im Snippet, das zieht den Blick.
  3. Aktive Sprache – „Erfahre", „Lerne", „So funktioniert es".
  4. Call-to-Action – „Jetzt anfragen", „Mehr erfahren".
  5. Differenzierung – warum dein Treffer und nicht der über/unter dir?

Beispiele

Schlecht: „Hier finden Sie Informationen zum Thema SEO."

Gut: „SEO Freelancer aus Essen mit 10 Jahren Journalismus-Erfahrung. Strategie, Content, KI-Prozesse. Transparente Preise. Jetzt anfragen."

Häufige Fehler

  • Description fehlt komplett – Google generiert dann oft generische Texte.
  • Identische Description über alle Seiten – schwächt die Differenzierung.
  • Zu lange Description – wird abgeschnitten.
  • Kein CTA – verschenktes Conversion-Potenzial.
  • Keyword-Stuffing – wirkt spammy.

Meta Description und Social Sharing

Wenn keine Open-Graph-Description (og:description) gesetzt ist, nutzen viele Plattformen (LinkedIn, Slack, X) die Meta Description als Vorschau-Text. Das macht sie auch für Social Sharing relevant.

Wann lohnt sich Optimierung besonders?

Bei Seiten, die in der Google Search Console auf Position 4–10 ranken: Hier ist die CTR-Steigerung der schnellste Weg zu mehr Traffic – ohne dass sich am Ranking etwas ändert.

Kurz gesagt: Die Meta Description ist deine Werbeanzeige in der SERP. Schreib sie wie eine – mit Versprechen, Keyword und Call-to-Action.
