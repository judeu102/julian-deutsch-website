Core Web Vitals

Core Web Vitals sind Googles offizielle Performance-Kennzahlen für Webseiten. Sie messen, wie schnell und stabil eine Seite im Browser des Nutzers wirklich rendert – und sind seit 2021 ein bestätigter Ranking-Faktor.

Was sind Core Web Vitals?

Die Core Web Vitals sind drei Metriken, die Googles Page Experience-Bewertung bestimmen. Sie messen Ladegeschwindigkeit, visuelle Stabilität und Interaktivität – also wie sich eine Seite für reale Nutzer anfühlt.

Die drei Metriken im Detail

LCP – Largest Contentful Paint

Misst die Zeit bis das größte sichtbare Element (meist Hero-Bild oder Headline) gerendert ist.

  • Gut: ≤ 2,5 Sekunden
  • Verbesserung nötig: 2,5 – 4 Sekunden
  • Schlecht: > 4 Sekunden

CLS – Cumulative Layout Shift

Misst, wie viel sich das Layout während des Ladens unerwartet verschiebt – z.B. wenn ein Bild ohne reservierten Platz nachlädt und Text nach unten schiebt.

  • Gut: ≤ 0,1
  • Verbesserung nötig: 0,1 – 0,25
  • Schlecht: > 0,25

INP – Interaction to Next Paint

Seit März 2024 die neue Interaktivitätsmetrik (ersetzt FID). Misst, wie schnell die Seite auf Klicks und Eingaben reagiert.

  • Gut: ≤ 200 Millisekunden
  • Verbesserung nötig: 200 – 500 Millisekunden
  • Schlecht: > 500 Millisekunden

Warum sind Core Web Vitals SEO-relevant?

Google bestätigt: Page Experience ist ein Ranking-Faktor. Bei zwei sonst gleichwertigen Seiten gewinnt die mit besserer Performance. Bei einzigartigem Content kann dieser zwar trotz schwacher Vitals ranken – aber jede Verbesserung der Vitals reduziert die Absprungrate und steigert die SERP-Performance.

Wie messe ich Core Web Vitals?

  1. Google Search Console – Bericht „Core Web Vitals" zeigt aggregierte URL-Daten aus dem Chrome User Experience Report (CrUX).
  2. PageSpeed Insights – Live-Test einzelner URLs.
  3. Lighthouse (in Chrome DevTools) – lokales Lab-Audit.
  4. Web Vitals Chrome Extension – Echtzeit-Werte beim Surfen.

Wie verbessere ich die Core Web Vitals?

LCP optimieren

  • Hero-Bilder als WebP/AVIF in passender Größe ausliefern.
  • Server-Response-Time reduzieren (Hosting, Caching).
  • Render-blockierendes CSS/JS eliminieren.
  • Wichtige Ressourcen mit preload markieren.

CLS optimieren

  • Bilder und iFrames mit expliziten width/height-Attributen.
  • Webfonts mit font-display: swap und Fallback-Strategie.
  • Werbung und Embeds in fixe Container packen.
  • Kein Content per JavaScript über bestehenden Text einfügen.

INP optimieren

  • JavaScript-Bundles aufteilen und nur Notwendiges laden.
  • Lange Tasks zerlegen (Web Workers, Idle Tasks).
  • Third-Party-Scripts (Analytics, Chat) defer/async laden.
  • Event-Handler entrümpeln.

Field Data vs. Lab Data

Wichtig zu unterscheiden:

  • Field Data – echte Nutzerdaten aus Chrome (CrUX). Das, was Google fürs Ranking nutzt.
  • Lab Data – simulierte Tests (Lighthouse). Gut für Entwicklung, aber nicht ranking-relevant.
Kurz gesagt: Core Web Vitals sind nicht der größte Ranking-Faktor – aber sie sind der einzige, der gleichzeitig Conversion und SEO verbessert. Doppelte Wirkung pro investierter Stunde.
