Google Search Console

Die Google Search Console (GSC) ist Googles offizielles, kostenloses Tool für Webmaster und SEOs. Sie zeigt, wie deine Website in der Google-Suche performt – mit Daten, die kein Drittanbieter so präzise liefert.

Was ist die Google Search Console?

Die Google Search Console – früher Webmaster Tools – ist ein kostenloser Service von Google. Sie liefert Daten direkt aus Googles Suche-Index und ist Pflicht-Setup für jede Website, die organisch sichtbar werden will.

Welche Daten liefert die GSC?

Performance-Bericht

  • Klicks – wie oft deine Treffer in den SERPs geklickt wurden.
  • Impressionen – wie oft sie überhaupt angezeigt wurden.
  • CTR (Click-Through-Rate) – Klicks geteilt durch Impressionen.
  • Durchschnittliche Position – auf welcher Position deine Treffer im Schnitt erschienen sind.
  • Filter nach Keyword, URL, Land, Gerät, Datum.

Indexierungs-Bericht

  • Welche Seiten sind indexiert?
  • Welche sind ausgeschlossen – und warum (Noindex, Canonical, 404, etc.)?
  • Crawl-Probleme.

Core Web Vitals

Aggregierte Felddaten zu LCP, CLS und INP aus dem Chrome User Experience Report.

Mobile Usability

Probleme bei der mobilen Darstellung – z.B. zu kleine Touch-Targets oder Viewport-Fehler.

Strukturierte Daten

Validierung von Schema.org-Markup für FAQ, Article, Product, Breadcrumb usw.

Sitemap-Bericht

Status der eingereichten XML-Sitemaps.

Backlinks

Welche externen Domains verlinken auf dich? Welche internen Links sind die stärksten?

Manuelle Maßnahmen & Sicherheitsprobleme

Hat Google manuell etwas an deiner Domain beanstandet? Hier siehst du es zuerst.

Wie richte ich die Google Search Console ein?

  1. Anmelden auf search.google.com/search-console mit Google-Account.
  2. Property hinzufügen (Domain-Property bevorzugt – deckt alle Subdomains und HTTP/HTTPS ab).
  3. Inhaberschaft per DNS-Eintrag, HTML-Datei, Google Tag oder Google Analytics verifizieren.
  4. Sitemap einreichen.
  5. 1–3 Tage warten, bis erste Daten kommen.

Wichtigste Use-Cases im Tagesgeschäft

  • Quick-Wins finden – Keywords auf Position 4–10: hier ist die CTR-Steigerung der schnellste Hebel.
  • Indexierungsprobleme aufdecken – warum wird eine wichtige Seite nicht indexiert?
  • Core Web Vitals überwachen – siehe Core Web Vitals.
  • Algorithmus-Updates erkennen – plötzliche Traffic-Drops im Performance-Report.
  • Neue URLs zur Indexierung anstoßen – per URL-Inspektion „Indexierung beantragen".

GSC vs. Google Analytics

  • GSC: Daten aus der Suche – wie kommen Nutzer zur Website?
  • GA4: Daten auf der Website – was machen Nutzer dort?
  • Beide Tools verbinden lohnt sich – GSC-Daten erscheinen dann auch in GA4.

Tipp: Filter speichern

Klick auf die Performance-Tabelle, Filter setzen (z.B. „Position > 3 und Position < 11"), und URL kopieren. So bekommst du jederzeit deine wichtigsten Quick-Win-Listen wieder.

Kurz gesagt: Wer SEO ohne Google Search Console macht, fliegt blind. Sie ist die einzige Quelle für echte Google-Daten – und sie ist kostenlos.
